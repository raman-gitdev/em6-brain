# Core glossary
- Origin = from, depart from, departure place, pickup, shipper, warehouse/W/H/depot the goods leave from.
- Destination = to, delivery, consignee. A district/region/area/zone column usually = destination.
- Lane = origin->destination pair. Zone = places sharing one price (zone chart -> zone, price matrix -> price).
- Chargeable weight = max(actual, volume weight); volume = LxWxH cm / divisor (air 6000, express 5000; the file's rule wins).
- Band "Up to 10 kg": use the first band >= chargeable weight. "Over 100 kg add every 10 kg" = add per extra 10 kg.
- Basis: per shipment, per kg, per 100 kg, per truck, per km, per pallet, per container. Minimum = lowest charge.
- LTL = groupage = consolidated (shared, by weight). FTL/charter = whole vehicle (by truck, often by km).
- Freight = base price. Surcharge = fuel/DG/peak on top. Accessorial = extra service. Tax/insurance usually excluded.
- Tariff = rate card = rate sheet = exhibit. Freight audit = invoice vs contract tariff. Accrual = expected cost booked early.
- DTD/DTA/ATA/ATD = door/airport scopes; EM6 service codes are carrier-specific.
